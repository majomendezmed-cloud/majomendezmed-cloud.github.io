# Portafolio profesional — Majo Méndez

Sitio estático bilingüe (español/inglés) preparado para GitHub Pages.

## Publicarlo en GitHub Pages
1. Crea un repositorio público en GitHub llamado `majo-mendez.github.io` si tu usuario de GitHub es `majo-mendez`. Si tu usuario es otro, cambia `majo-mendez` por tu nombre de usuario exacto.
2. Sube el contenido de esta carpeta al nivel raíz del repositorio. Debes ver `index.html`, `styles.css`, `script.js` y la carpeta `assets` directamente en la página principal del repositorio.
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**; selecciona `main` y `/(root)`, y pulsa **Save**.
5. Espera a que termine la publicación. GitHub mostrará la URL en la sección Pages. La primera publicación puede tardar varios minutos.

## Editar
- El texto traducible está en `index.html` mediante atributos `data-es` y `data-en`.
- Colores y diseño están en `styles.css`.
- El botón de idioma está en `script.js`.

Nota: GitHub Pages hace público el contenido del sitio. Revisa los datos personales que deseas publicar antes de subirlo.
